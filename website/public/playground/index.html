Playground

Type Snowflake SQL. SQLQuack parses it, checks it, translates it to DuckDB SQL and runs it in DuckDB, all in your browser. Each stage passes or fails on its own, so you can see which step stopped and where.

Hover an underline for its diagnostic.

Sources: the tables your SQL reads

Each table's columns and Snowflake types, as a project's sources/*.yml file declares them. Unquoted names are upper case.

Fixture rows for DuckDB

DuckDB SQL run after the sources' tables are created, before the translated query.

Known differences and strict mode

Where DuckDB can differ from Snowflake. Tick one to allow it; each change from the default becomes a line under [allow].

Refuses every known difference, whatever [allow] says, as --strict does.
