SQLQuack's tokenizer and parser started from code derived from
[Polyglot](https://github.com/tobilg/polyglot), by Tobias
([@tobilg](https://github.com/tobilg)). Its DuckDB result-type rules are ported from Polyglot's
engine type rules. Thank you, Tobias.

Thanks also to [SQLGlot](https://github.com/tobymao/sqlglot), by Toby Mao. Polyglot is inspired by
SQLGlot, and SQLQuack uses the Snowflake SQL of SQLGlot's test suite as case inputs, with the
expected answers recorded from Snowflake itself.

Both are MIT-licensed. Their licences and the exact files concerned are in
[`THIRD_PARTY_NOTICES`](https://github.com/sqlstack-io/sqlquack/blob/main/THIRD_PARTY_NOTICES).
